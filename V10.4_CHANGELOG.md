# Aviance SEO Pro Max v10.4.0

- Added SSRF protection: audit targets, discovered links and redirect hops are resolved and checked against private/loopback/link-local/cloud-metadata ranges before any request is made, for both the HTTP fetch path and the Playwright-rendered path.
- Added security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, same-origin `Content-Security-Policy`, conditional `Strict-Transport-Security`) to every response.
- Added environment-driven CORS (`CORS_ORIGINS`), off by default.
- Added a per-client-IP rate limiter (`RATE_LIMIT_PER_MINUTE`) on the crawl/report endpoints.
- Hardened the source-ZIP analyzer against decompression-bomb archives (per-file and cumulative decompressed-byte caps, entry-count cap).
- Added structured request logging and a generic-message global error handler so unexpected failures no longer risk leaking internals to the client.
- Added a customer-facing "Client View" results tab (category-level Good/Needs Improvement/Poor ratings only) with a WhatsApp click-to-chat CTA prefilled with the site and score. Full technical detail (codes, evidence, developer fixes) remains on the existing internal tabs.
