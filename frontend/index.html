📐 Link Intelligence Methodology & Boundaries

1. Internal Page Equity Score (IPES) & Platform Authority Index (PAI)

Calculated strictly from first-party on-site crawl evidence using an iterative PageRank power algorithm (damping factor d = 0.85, 30 iterations) across all discovered canonical pages:

PR(u) = (1 - d) / N + d * Σ [ PR(v) / L(v) * W(v) ] * DepthMultiplier(u)
  • Status Code Weights W(v): HTTP 200 = 1.0, 3xx Redirects = 0.5, 4xx/5xx Errors = 0.0.
  • Crawl Depth Penalty: Pages at depth 3 receive a 0.92 damping multiplier; depth ≥ 4 receives 0.85.
  • Orphan Page Rule: Pages discovered with 0 internal inbound links receive an IPES of 0.0.
  • PAI Domain Score: The weighted average equity of the top 15% highest-equity page hubs.

2. Third-Party External Backlink Indexes

External referring domains, live backlinks, and historical link velocity are retrieved directly from licensed data providers (DataForSEO Backlinks API or OpenPageRank).

When an external provider is not connected, the application will never generate fabricated backlink numbers. Instead, it clearly states provider unavailability while displaying verified on-site link equity calculations.

3. Search Engine Ranking Disclaimer

Neither the Platform Authority Index (PAI) nor third-party Domain Rank scores are endorsed by or affiliated with Google LLC. They represent algorithmic link architecture models and must never be represented as guaranteed Google ranking indicators.
