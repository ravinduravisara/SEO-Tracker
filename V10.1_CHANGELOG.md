# Aviance SEO Pro Max v10.1.0

## Universal crawl
- Fixed asynchronous sitemap queue merge/early-exit bug.
- Added conservative URL transport/hostname fallback after transport-level failures.
- Preserved valid HTTP error responses as evidence; fallbacks do not hide real 4xx/5xx responses.
- Added transport attempt diagnostics to page data.
- Internal safety ceiling is 25,000 URLs by default; no maximum-pages input is exposed in the UI.

## Audit intelligence
- Added duplicate-H1 cross-page signal.
- Added canonical-not-in-sitemap signal.
- Added transport-fallback signal.
- Issue source/evidence classes are surfaced in results and exports.
- Overall score normalization now uses declared category weights with a bounded severity penalty.

## UX/reporting
- Page URLs are clickable for a fresh one-page re-check.
- Added one-click download of all PDF report types.
- Full report pack, CSV, JSON and A-Z guide remain available.
- Ollama remains optional; core recommendations never depend on it.

## Accuracy boundary
The crawler does not bypass login walls, CAPTCHA, paywalls, WAF challenges or other access controls. Search volume, rankings, traffic, backlinks and field Core Web Vitals require their real provider/browser/field integrations.
